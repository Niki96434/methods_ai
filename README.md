# Курс посвящен заданиям по методам искусственного интеллекта и нейросетевым технологиям анализа данных

Датасет https://archive.ics.uci.edu/dataset/73/mushroom

## Запуск скриптов через uv:

1. Установочный скрипт через curl:
```
curl -LsSf https://astral.sh/uv/install.sh | sh
```
2. Синхронизация зависимостей с uv.lock файла в виртуальном окружении.

```
uv sync
```
3. Запуск скриптов (из корня проекта):
```
uv run cases/**/*.py
```

## Общепринятые правила:

snake_case — имена переменных, функций, методов модулей

CamelCase — имена классов

yet-another-package — названия пакетов

CONSTANT — константы
